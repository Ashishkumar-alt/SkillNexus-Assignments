# To-Do List REST API

This is a simple To-Do List REST API built using Node.js, Express.js, and MongoDB.

## Features

- Add a task
- View all tasks
- Update a task
- Delete a task

## API Endpoints

POST `/api/tasks` - Add task

GET `/api/tasks` - Get all tasks

PUT `/api/tasks/:id` - Update task

DELETE `/api/tasks/:id` - Delete task

## How to Run

```bash
npm install
node server.js
```
