# SkillNexus Assignments

This repository contains backend assignments completed as part of the SkillNexus internship program.

## Assignments

### 1. To-Do List REST API

A simple REST API built using:

- Node.js
- Express.js
- MongoDB
- Mongoose

Features:

- Create a task
- Get all tasks
- Update a task
- Delete a task

Folder: `todo-list-api`

---

### 2. User Authentication API

A user authentication backend built using:

- Node.js
- Express.js
- MongoDB
- bcryptjs
- JSON Web Token (JWT)

Features:

- User registration
- Password hashing
- User login
- JWT authentication

Folder: `user-auth-api`

---

### 3. Notes App Backend

A secure notes backend built using:

- Node.js
- Express.js
- MongoDB
- bcryptjs
- JSON Web Token (JWT)

Features:

- User registration
- User login
- Create notes
- Get user's notes
- Update notes
- Delete notes
- JWT protected routes

Folder: `notes-app`

---

## How to Run

Open the required assignment folder and install dependencies:

```bash
npm install
```
